# PeopleCare AI v3.3 — Engineering polish

This package is based on the existing v3.2 source. It adds keyboard focus visibility, restrained interaction feedback, responsive breakpoints for narrower screens, and image overflow protection.

## Scope / honest status
- Existing application features and architecture are retained.
- This is not a ground-up rebuild, production deployment, or verified end-to-end release.
- Maya's image is not a rigged 3D character; animated avatar/voice/provider integration requires assets and configuration.
- Validate locally: backend startup, Vite startup, report submission, assistant configuration, and mobile layout.
